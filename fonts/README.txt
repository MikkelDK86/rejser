Optional: the design was drawn in "Space Grotesk" (SIL Open Font License, free from Google Fonts).

To use it:
  1. Download the variable font and save it here as  SpaceGrotesk.woff2
     (fonts.css already points to that file name).
  2. In sw.js add  'fonts/SpaceGrotesk.woff2'  to the SHELL list and bump VERSION.

Without the file the app falls back to your phone's system font and works exactly the same
(the browser may log one harmless 404 for the missing font in the developer console).
